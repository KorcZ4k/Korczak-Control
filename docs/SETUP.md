# Configuração inicial

## Requisitos

- Node.js 20 ou superior
- npm

## API

```bash
cd backend/KorczakControlAPI
npm install
cp .env.example .env
npm run dev
```

## Teste

Abra:

```text
http://localhost:3000/health
```

A resposta deve conter `status: ok`.

## Android

A pasta `android/KorczakControl` permanece reservada para a criação do projeto Android nativo nas etapas posteriores. Não existe ainda um projeto Android compilável nesta fase.
